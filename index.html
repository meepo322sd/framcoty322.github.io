Featured Project: RPi WireGuard "Implant"

The "Mr. Robot" Motivation:

This project is inspired by Red Team scenarios where an attacker (like Elliot) gains physical access to a building and leaves a Raspberry Pi plugged into a hidden network port. The device automatically establishes a secure VPN tunnel to an external server, giving the attacker a persistent foothold *inside* the corporate network. From home, they can now pivot, scan, and audit the entire internal network.

This repository provides the scripts and configurations to build that exact tool.

  • Provides persistent, remote access over WireGuard
  • Uses a Raspberry Pi as a portable, drop-in "implant"
  • Routes all traffic from a custom WiFi AP through the secure tunnel
  • Includes VNC for full remote graphical access to the Kali desktop
